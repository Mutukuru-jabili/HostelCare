# HostelCare Frontend

The frontend is a React application built with Vite. From this folder, run:

```bash
npm install
npm run dev
```

Vite serves the app at `http://localhost:5173`. The frontend calls the Spring Boot API at `http://localhost:8909/api` by default. Override this with `VITE_API_BASE_URL` when the backend is hosted elsewhere.

For the full project description, setup, database schema, workflows, and interview questions, see [the project documentation](../docs/PROJECT_DOCUMENTATION.md).
